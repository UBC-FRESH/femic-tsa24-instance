femic-tsa24-instance
=======================

FEMIC deployment instance for **TSA 24** — one of the five WBI birds AOI
management units (TSAs 08/16/24/40/41). This instance builds the forest-estate
model inputs and the ws3 handoff consumed by the
`WBI birds engine <https://github.com/UBC-FRESH/wbi-birds>`_.
