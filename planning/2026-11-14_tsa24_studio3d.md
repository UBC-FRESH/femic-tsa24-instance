# TSA 24 — Studio 3D scene pack

**Date:** 2026-11-14  
**Instance:** `femic-tsa24-instance`  
**Status:** large-landscape rollout; no model coefficients changed.

## Scene

- `GET /api/studio3d` serves `planning/studio3d/tsa24_scene.json`.
- Terrain: public SRTM 1-arcsecond tiles at a 300 m scene grid.
- Forest: 458,708 TSA 24 blocks from `tsa24-blocks-overview.geojson`,
  aggregated to 1 km forest cells (73,092 cells).
- Ages from the block overview; treatment from `tsa24-ltsy-schedule.csv`.
- No local CHM; heights are age-derived visual values.
- All-tree mode disabled for the large landscape.
- No canopy-light raster; block outlines and real-time tree shadows default off.
- Default view distance 350 m.

## Reproduce

```bash
python scripts/build_studio3d_scene.py
```

The first run downloads public SRTM tiles into `data/downloads/srtm/` (ignored by
git). Later runs reuse the cache.
